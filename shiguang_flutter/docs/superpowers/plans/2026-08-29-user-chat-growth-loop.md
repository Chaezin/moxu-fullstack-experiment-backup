# 用户聊天持久化与自动成长卡片实施计划

> 实施遵循测试驱动：每项行为先写失败测试，确认失败原因，再写最小实现并运行完整回归。

## 阶段 1：后端基础与用户隔离

1. 新建 `backend` Python 包及测试环境。
2. 编写健康检查与应用配置测试，建立 FastAPI 应用工厂。
3. 编写用户注册/登录、令牌刷新与退出测试。
4. 实现用户、刷新令牌模型及密码、令牌安全服务。
5. 编写跨用户访问失败测试，建立统一认证依赖。

## 阶段 2：聊天持久化

1. 编写创建、查询、更新、软删除会话测试。
2. 编写消息顺序、用户归属和 `client_message_id` 幂等测试。
3. 实现会话和消息仓储、服务与 API。
4. 编写重新登录后恢复历史记录的集成测试。
5. 增加 outbox 事件，验证消息和事件同事务提交。

## 阶段 3：技能与自动卡片

1. 定义结构化分析结果和分析器接口，使用测试分析器建立契约测试。
2. 编写任务幂等、失败重试和分析游标测试。
3. 实现技能归一、证据去重和置信度合并。
4. 编写“低于阈值不生成、达到阈值生成、同一事件不重复”的测试。
5. 实现成长卡片、技能关联和每日补偿汇总。
6. 接入可配置 AI 提供方；缺少密钥时保持任务可重试，不影响聊天。

## 阶段 4：前端接入

1. 为 API 客户端、用户缓存隔离和恢复逻辑增加 JavaScript 行为测试。
2. 将演示 API 切换为可配置真实后端，保留显式演示模式用于离线开发。
3. 登录后从后端恢复会话、消息、技能和卡片。
4. 发消息时生成 `client_message_id`，实现安全重试。
5. 将“收入卡片”改为“查看成长卡片”，移除手动生成路径。
6. 接入分析状态和新卡片通知。

## 阶段 5：删除、迁移与发布

1. 编写聊天软删除后卡片保留、原文引用清除测试。
2. 编写卡片编辑和独立删除测试。
3. 提供 PostgreSQL 迁移、开发环境启动配置和环境变量模板。
4. 提供演示本地数据迁移说明，不自动上传浏览器隐私数据。
5. 运行后端单元/集成测试、Flutter 测试、静态检查和 Web 构建。
6. 在预览环境验证登录恢复、多用户隔离、自动卡片和删除流程。
