# 研究证据知识库

版本：1.1  
复核日期：2026-08-26  
用途：为日常对话、反馈卡、个人档案和月年回顾提供可追溯的研究依据。

## 使用方式

这组文件是经人工整理的证据卡，不是把论文全文交给模型。每轮最多加载 1—2 份与当前议题直接相关的证据卡：

| 用户议题 | 读取文件 |
|---|---|
| 家务、照护、时间被切碎、隐形负担 | `01-家庭劳动与结构处境.md` |
| 不知道自己想要什么、缺少选择感或信心 | `02-自主性与成长.md` |
| 想改变但不知道如何开始 | `03-行动与行为改变.md` |
| 想倾诉、犹豫、需要回应或同路人 | `04-支持性对话与社会支持.md` |
| 整理经历、生成反馈卡或成长报告 | `05-叙事身份与成长记录.md` |
| 选择来源、核对原文和适用范围 | `sources.md` |

`implementation-references.md` 只供产品设计与开发审核，不进入日常对话路由。

## 接入状态

- 已接入对话证据：S01—S15，以及受限使用的 N01、N06、N07。
- 易变安全来源：N05，仅在商业风险场景按有效期加载。
- 候选、暂不用于具体结论：N02、N03、N04。
- 实施参考、不进入日常对话：S16、S17。

## 证据等级

- A：政府、联合国机构、世界卫生组织等正式报告或指南。
- B：同行评审的奠基性论文、系统综述或高影响理论论文。
- C：专业组织的实践说明；只能作为表达方法参考。

证据等级不代表可以直接给用户下结论。研究对象、国家、年代和应用场景可能不同，模型必须先听取用户自己的描述。

## 总原则

1. 同时考虑个人感受与现实条件，不能把缺时间、缺资源、家庭分工或照护压力解释成意志薄弱。
2. 用户是自己生活的解释者。理论用于帮助提问和整理，不能用于给用户贴标签、打分或宣布“真正原因”。
3. 摄像头表情、声音特征和模型推断都只是低可信线索，不能作为心理判断或档案事实。
4. 只有用户明确希望行动时，才使用行动工具；用户可拒绝、暂停或改变目标。
5. 这套知识不授权模型开展心理诊断、心理治疗、危机干预或关系裁决。
6. 输出通常不需要罗列论文名称；涉及事实性数据、用户主动询问依据或团队审查时，才展示来源。

## 维护

- 每半年检查一次链接、版本和新证据，最后复核日期写入 `sources.md`。
- 新来源必须记录：来源类型、核心发现、适用范围、限制、可用于什么、不能用于什么。
- 来源登记统一维护原始入口、最近成功入口、核验日期、核验范围、状态、复核时间和使用边界。
- 不能只凭二手文章、媒体摘要或流行心理学内容修改对话规则。
