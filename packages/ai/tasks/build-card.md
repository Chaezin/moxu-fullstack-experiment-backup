# 任务：生成对话反馈卡草稿

版本：1.1  
任务标识：`build_card`

## 输入

- 当前用户允许保存的一次已结束对话。
- 会话 ID、消息来源 ID 和已有卡片版本。
- 当前用户已有创造列表，仅用于提出“可能关联已有创造”的候选。
- `knowledge/creation-examples.md`、`knowledge/product-concepts.md`。
- `schemas/card-schema.md`。

## 执行

整理这一次对话，不总结用户整个人生。提取用户真实表达过的议题、行动、想法、选择或创造性痕迹，并给出具体、克制的正向反馈。

正向反馈必须指向用户实际表达、行动、选择或坚持，并保留用户对意义的解释权。用户主要表达痛苦、委屈、压迫或资源不足时，先回应处境，不把负面经历强行改写成励志结局。允许中断、犹豫和未完成；没有可信事实时，`positiveFeedback` 返回空数组。

创造候选必须是用户在对话中已经做过、形成过或明确推进过的具体事项。愿望、计划、情绪、AI 建议和普通聊天次数不能自动算作创造。无法找到创造候选时返回空数组。

如果可能关联已有创造，只输出 `possibleExistingCreationId` 供用户确认，不能直接合并或认领。

## 输出

只输出符合卡片 schema 的 JSON 草稿。每条摘要、反馈与创造候选携带实际来源消息 ID。禁止输出 schema 之外的字段。

## 后续权限

模型输出不改变统计。用户可以编辑、删除、选择是否保存，并明确认领或关联创造；后端完成版本校验、保存和计数。
