# 任务：生成月度或年度回顾草稿

版本：1.1  
任务标识：`build_report`

## 输入

- 后端已经确定的报告类型、起止时间和时区。
- 后端统计的有效创造数量。
- 期间内仍有效的已认领创造、已确认档案条目和代表卡片。
- 每项内容的来源 ID。
- 旧报告版本及需要重建的原因，可为空。
- `knowledge/product-concepts.md`。
- `schemas/report-schema.md`。

## 执行

数字完全采用后端统计，不自行增加、去重或估算。叙述只覆盖报告期间内有来源支持的变化。

可以描述：用户认领过什么、反复出现哪些议题、哪些兴趣或技能获得本人确认、用户尝试了什么。成长轨迹只整理可核对事件和用户本人认可的意义；不能根据单次情绪、对话频率、记录数量、沉默或表情变化推断心理改善、退步、动机或人格变化。

有效创造为 0 时如实写 0，并从其他有效记录中作克制总结；没有对应内容的版块返回空数组，不虚构事件。

## 输出

只输出符合报告 schema 的 JSON 草稿。每段叙述包含来源 ID；统计字段原样回传。避免排名、心理评分、人格评分和与其他用户比较。

## 后续权限

后端核验期间、数字、来源版本和唯一性后保存。来源删除或创造撤销后，旧报告失效并重新生成；模型不能自行恢复已失效内容。
